## Deploy to GitHub Pages

```bash
git init

git commit -m "Initial: Schwarzenegger Iron Programme"
git remote add origin https://github.com/imenesayah-netizen/schwarzenegger-iron-programme.git
git push -u origin main
```

Then in GitHub → Settings → Pages → Source: **main branch / root**.
